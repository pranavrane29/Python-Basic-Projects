# ❤️ Heart Disease Prediction System

## 📌 Project Description

This project predicts whether a patient is likely to have heart disease using a Machine Learning model based on Logistic Regression.

The application is built with Streamlit and allows users to enter patient details through a simple web interface.

---

## 🚀 Features

- Predict Heart Disease
- Interactive Streamlit Interface
- Logistic Regression Model
- Automatic Data Preprocessing
- StandardScaler Integration
- One-Hot Encoding
- Professional ML Pipeline

---

## 🛠 Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- Streamlit
- Joblib
